  and acceptance evidence; nothing in this index closes them.
- Native accessibility is limited to the behavior actually exercised in
  [ADR-009](adr/009-supported-platform-and-accessibility.md). Native Linux/Windows and
  OS screen-reader/focus support are not inferred from headless or portable execution.
- Python/WASM are executed proof adapters, not installed public distributions.
- Fonts and export modes retain the explicit resource/embedding restrictions in
  [ADR-003](adr/003-font-and-renderer-capability-route.md).
- Resolve the repository license/copyright/registry metadata and existing dependency
  advisories before external distribution; [ADR-010](adr/010-package-and-release-policy.md).

[support matrix](support-matrix.md) and per-package reports provide executable routes
