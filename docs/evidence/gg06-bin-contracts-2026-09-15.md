# GG-06 bin contracts and qualification

Implementation on `96d044d` plus the owned worktree implements GG2-02/05 and
FIX-GG06 through one core bin owner. `GgplotBinOptions` adds right/left fuzzy
closure, explicit or automatic breaks, width/center/boundary alignment, padding,
source weights, and generated count/density/ncount/ndensity. The ggplot profile
resolves reference defaults; absent options under LibraryV1 retain legacy bins.
The `[0,1,2]` sentinel gives `[2,1]` under the profile and `[1,2]` under LibraryV1.

Exact row membership remains a UInt64 provenance count. Weighted generated count
is Float64; signed density divides by width and total absolute bin count. Missing
and NaN weights contribute zero; infinite/nonrepresentable sums fail explicitly.
Undefined normalized values are nullable in generated schema v2. Explicit new
options or generated fields require definition v72, including expression reads.
Reading a normalized field from a legacy schema fails rather than dropping marks.

Padding is applied after classification, so new empty intervals cannot absorb
outliers. Fuzzy membership uses the same helper in batch/incremental code. Weighted
bins deliberately use exact batch recomputation; the capability/metrics report
that fallback. Append, correction, removal and retention compare exact membership,
weighted values and immutable earlier snapshots against fresh batch preparation.
