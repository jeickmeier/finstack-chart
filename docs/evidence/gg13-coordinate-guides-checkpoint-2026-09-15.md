# GG13 coordinate guide checkpoint

This is focused guide/layout evidence, not GG13 package acceptance. The parent owns final combined checks and hosts; the coordinate owner owns mark projection, subdivision, clips and inverse/inspection. No interpreter or new dependency entered runtime.

`tools/reference/r/coordinate-guide-controls.R` captures nine actual ggplot2 4.0.3 / R 4.6.1 guide configurations after `ggplot_gtable`: full and partial radial arcs, reversed angle/radius, theta-y, secondary guides, explicit angular text angle, inside/explicit radial axes and partial outside axes. `fixtures/parity/ggplot2/coordinate-guide-controls.json` retains selected typed values, transformed key coordinates, primary/secondary radii, merged seam labels, angular label rotations and bounding boxes. Six additional source cases retain wrap/grid rejection of free-x/free-y/free scales with a fixed Cartesian ratio. Capture log: `/private/tmp/gg13-guide-reference.log`.

Runtime guide geometry consumes the existing resolved major/minor ticks, labels, styles and guide identities. It calls the shared coordinate map and destination-bounded path subdivision. It does not select its own breaks. The parent-owned `coordinate_guides_training` helper reselects guide values for coordinate viewports through the existing axis/guide owners, retaining unchanged mark scales; relocation occurs once afterward. Cartesian flip swaps guide sides and nonlinear coordinates relocate tick positions before label measurement. Titles follow the resolved guide sides. Categorical candidates and explicit ticks outside the coordinate view are filtered without changing source populations.

Measured panel aspect is fitted into the available rectangle, then axes are resolved on that final rectangle. Facet panels use the same measured solver. Under the ggplot profile, free facets with an explicit fixed Cartesian ratio reject, matching the source; LibraryV1 retains the existing free-facet behavior.

Polar and radial furniture retain separate source policies over one map: polar labels center at radius .45, angular ticks/domain are absent, spokes reach .45 and an outer .45 grid ring is present; polar panel fill remains rectangular. Radial primary angular guides sit on the physical outer radius, secondary guides on the inner radius with inward justification; full-circle endpoint labels merge into the retained last tick. Radial plain backgrounds use the shared sector clip; gradient backgrounds use the parent-owned destination gradient mask. Inside/explicit radial axes and outside cardinal axes use the existing selected radial values. Explicit angular label rotation uses upright rules; rich text continues through the shared shaper. Its rotation sin/cos now use pinned libm to avoid platform-dependent new angular guide output.

Typed angular values avoid an unnecessary destination-pixel roundtrip. A public secondary-guide author exposed a seam bug where an exact final source value became just below a full turn after that roundtrip; the fix uses the shared typed coordinate-limit conversion and direct value projection. Source seam tolerance was not loosened.

Glyphs bypass a second coordinate warp, preserving circular destination dimensions.
