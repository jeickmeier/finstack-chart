# GG-06 count and summary contracts — 15 September 2026

Shared core implementation adds opt-in reference count and summary policies while preserving raw CountSpec/SummarySpec outputs. This is count/summary evidence within GG-06, not package acceptance.

- `GgplotCountOptions`: numeric position plus declared group partitions, signed weights, missing weights contributing zero, count proportions and reference default/explicit widths. Exact UInt64 membership count remains `Count`; signed numeric sums are `WeightedCount` and normalization is `Proportion`.
- `GgplotSummaryOptions`: response summaries at each unique predictor or within shared reference bins. Bins reuse GG-06 edge/closure kernels. Exact members and aggregate identity include each position/bin, so two outputs in one group do not alias provenance.
- `SummaryHelper`: mean/SE, mean/sample-SD, median/equal-tail range, mean/Student-t interval, percentile bootstrap with built-in seeded sampling or explicit resample indices, and independently composed scalar center/lower/upper functions. Existing stable mean, sum and quantile owners are reused. Student-t inversion uses a bounded incomplete-beta evaluation and bisection.
- Summary helpers are unweighted, matching the ggplot built-in functions' value-vector input. Count weights are separate. No claim of weighted Hmisc summaries is made.
- `MeanClBootSeeded` and `SummaryHelper::mean_cl_boot()` provide built-in 1,000-replicate bootstrap sampling, confidence 0.95, seed zero. SplitMix64 with rejection sampling generates unbiased indices independently for each source-key-ordered population, including unequal group sizes. It does not reproduce R's ambient RNG. `MeanClBoot` accepts explicit zero-based resample indices as an independent replay/oracle route.
- Primary Rust/Python/WASM methods: `ggplot_count`, `count_weight`, `count_width`, `summary_helper`, `summary_bins`; WASM also exposes the corresponding camelCase spellings. Existing x/y/group and generated StatAes mappings remain the only authoring engine.
- New generated fields are `WeightedCount`, `Proportion`, `Lower`, `Upper`, `Width`, with existing X/Y positions. Definitions use root-owned wire version 72; reference statistical output schema is version 2. Raw output schema remains version 1.

Source statements are based on ggplot2's pinned `R/stat-summary.R` helper dispatch and documented Hmisc helper contracts; full Hmisc execution remains an acceptance boundary.
