# GG17 device and platform matrix

This records implemented capabilities and evidence boundaries; compilation is not
platform playback certification. All encoders consume immutable core scenes with
explicit resources and no GPUI, browser, interpreter, current device or system-font
lookup. Parent owns cumulative acceptance and fresh-host publication comparisons.

Portable implementation means Rust code is shared on macOS, Linux, Windows and
wasm32; it does not assert a Windows/Linux runtime was executed for each row.
macOS native plus actual Python and Node/WASM publications are the current scoped
runtime evidence. Native callbacks are unsupported for every headless format.

## Source backend distinctions

Pinned R4.6.1/ggplot2 4.0.3 fixture `device-controls.json` captures22 actual TIFF
backend calls. Cairo supports none/LZW/JPEG/ZIP/LZW+predictor/ZIP+predictor/LZMA/
Zstd/WebP on that host. RLE and LERC produced no file, and those outcomes are
retained rather than mislabeled implementations. Quartz ignores non-default
compression with a warning. The portable exporter chooses explicit codec policy;
it does not silently substitute Quartz or Cairo behavior. PackBits is an explicit
portable option, not an alias claiming Cairo RLE parity.

## Save and lifecycle policy

Missing dimensions require an explicit current physical page. Units in/cm/mm/px,
positive scale, named/numeric DPI,50-inch source limit, extension inference,
explicit device override and numbered filename expansion are resolved without I/O.
Directory creation is opt-in. Python performs the requested final filesystem write;
WASM returns owned bytes plus the plan and performs no filesystem operation.
Retained FigurePages survive source figure disposal. Pages are capped at1024;
PDF/PS/TIFF obey the strictest captured output budget, while each raster page obeys
its own pixel budget. Custom-device output obeys both the supplied save budget and
the captured profile budget. Callback and encoder errors prevent final host writes.

## Bounded save/pages review

The PDF page loop, retained page handles and native/Python/WASM disposal paths were
reviewed together. One discrepancy was fixed: Rust custom callbacks now receive
the minimum of the caller save budget and the captured profile budget, matching
built-in enforcement. A regression observes the callback limit and rejects its
oversized output. Four focused save/page tests pass in
`/private/tmp/gg17-save-review-tests2.log`, including the original dimension,
callback failure/directory policy and exact single-page PDF regression.
Python/WASM save wrappers also release temporary options if option construction
throws before capture. Their source syntax checks pass; parent owns the fresh
actual-host rerun. No broader export audit is claimed.
