# GG10 canonical GAM numerical checkpoint

The new, unwired `grammar/model_gam.rs` implements the univariate Gaussian `y ~ s(x, bs='cs')` route with REML smoothing selection. It uses natural cubic cardinal splines, a centered smooth plus intercept, a curvature penalty with nullspace shrinkage, profile REML gradient selection, and conditional prediction covariance. It does not route GAM through LOESS, interpolation-only geometry, OLS or an external interpreter.

`Controls` contains basis dimension (default 10), optional explicit knots, a maximum selection-iteration count and convergence tolerance. `fit(x,y,weights,controls,max_cells)` returns `GamFit`; `predict(grid)` returns mean/standard-error pairs. Results expose the smoothing parameter in the raw curvature-penalty scale, residual variance, effective degrees of freedom and convergence status. To compare the raw smoothing parameter with mgcv's reported `sp`, divide reference `sp` by the captured penalty scale.

Numerical conventions matter for this route. The pinned `cs` construction assigns unequal small penalties to two nullspace directions. A generic eigensystem can therefore produce observably different smoothing. The original `model_symmetric.rs` owner uses Householder tridiagonal reduction, explicit fused arithmetic, numerical block deflation and Sturm-refined eigenvalue ordering, with orthogonal rotations for vectors. This is qualified for the captured spline matrices, not claimed as a replacement for every LAPACK capability. The spline second-derivative system uses a tridiagonal factorization. No foreign source code or runtime dependency was adopted.

Two investigations prevented false acceptance. Generic Jacobi and a private nalgebra 0.34.2 experiment did not preserve the source nullspace convention. Separately, mathematically equivalent type-7 knot arithmetic shifted knot values by approximately 2e-16 and changed predictions by approximately 3.6e-6. The shared quantile owner now evaluates `1 + (n - 1) * p`, and GAM constructs equally spaced probabilities with multiplication. The original prediction and matrix tolerances were retained throughout. All eight shared distribution tests passed after the narrow quantile change (`/private/tmp/gg09-type7-order.log`).

Source evidence is pinned to R 4.6.1, mgcv 1.9.4, reference R BLAS and LAPACK 3.12.1 on aarch64 macOS. `tools/reference/r/gam-controls.R` captures seven cases, including nonlinear, weighted, small basis, exact linear, constant, tied x and insufficient unique values, with predictions, standard errors, smoothing parameter, scale, effective degrees of freedom, model matrices, penalty matrices and eigenpairs. `gam-nullspace-controls.R` adds six controlled translations, retaining unscaled raw matrices before rescaling, eigenpairs and resulting shrinkage matrices. The mathematical spline construction is described in [mgcv's spline numerical source](https://raw.githubusercontent.com/cran/mgcv/master/src/mgcv.c); R's symmetric eigen interface is documented in [its LAPACK interface source](https://raw.githubusercontent.com/wch/r-source/trunk/src/modules/lapack/Lapack.c). Executed fixtures pin behavior independently of those moving source branches.

Validation: the isolated harness compiles the actual new model files with cached workspace dependencies. `/private/tmp/gg10-gam-kernels.log` records 12 tests passing. GAM means/standard errors retain 1e-7 tolerance; source shrinkage matrices retain 1e-10 tolerance; nondegenerate smoothing parameters retain 1e-7 relative tolerance. Automatic-1000 matches the existing pinned model fixture. Constant-response and insufficient-unique-x source failures, negative weights and allocation budgets are also exercised. Exact-linear predictions and negligible uncertainty qualify, but its numerically tiny smoothing parameter is not asserted equal to mgcv's similarly tiny value.

Remaining integration belongs to the shared ModelSpec/statistic/authoring owner. Other spline bases, generalized GAM families, multivariate formula terms, model registrations, broader near-singular matrices, cross-host numerical byte stability, pipeline mutation/filter/zoom behavior and publication inspection are not established by this checkpoint. GG10 remains open until coordinated runtime and acceptance evidence is complete.
