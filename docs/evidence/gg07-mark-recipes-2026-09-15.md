# GG-07 count, columns, rugs, curves and spokes

Canonical code lives in `grammar/recipe_marks.rs`, `layout/recipe_marks.rs` and the existing GG-06 count owner. Shared recipe/channel/projection integration is owned by the GG-07 lead; global wire, host runners and acceptance remain integration-owned.

- Reference columns use data-space resolution/width/justification and keep signed dependent values until positions run. They do not alter the legacy display-unit bar contract.
- Spokes calculate signed radius endpoints in calculation space, counterclockwise from positive x. Destination curves use grid's angle-skewed circular control polygon and the positive-shape rational X-spline basis (interior shape 0.5, interpolating endpoints), not a D3 curve alias. Subdivision is bounded and checks a 0.01 destination-unit approximation tolerance at quarter/mid/three-quarter points.
- Rugs draw selected physical panel edges, with lengths relative to the perpendicular panel dimension and explicit outside direction. Optional source coordinates are retained without inventing source zero values.
- StatSum opts into `GgplotCountOptions.joint_position` and additional `joint_aesthetics`. It aggregates joint positions and mapped source aesthetic values while retaining the original group for signed `n/sum(n)` proportions. Existing one-dimensional Count semantics, including absolute-count normalization, remain unchanged. `sum_count()` and `count_partition()` explicitly author this contract. WeightedCount/Y/Proportion reuse existing fields; wire 74 covers the new options.

Primary algorithm anchors: installed R 4.6.1 `grid:::calcControlPoints`, `grid:::calcCurveGrob`, `grid::xsplinePoints`; ggplot2 4.0.3 `GeomCurve$draw_panel`, `GeomBar$setup_data`, `StatSum$compute_panel`. The rational basis is the mathematical model in Blanc and Schlick, *X-splines: A Spline Model Designed for the End User*, SIGGRAPH 1995, also visible in [R's X-spline implementation](https://github.com/wch/r-source/blob/trunk/src/main/xspline.c). The local implementation independently expresses the positive-shape rational basis with translated knot indices eliminated; it does not add an R dependency.
